Create a file named main.rs and add the source code.

```rust
fn main() {
    println!("Hello, world!");
}
```

For compile use:

```bash
rustc main.rs
```

for execute:

```bash
./main
```

The first part is the main function:

```rust
fn main() {
    
}
```

In every Rust program, the entrypoint is `main` defined with `fn`. The parentheses `()` are used for arguments.

The function body is wrapped in `{}`

The body of the `main` function is:

```rust
println!("Hello, world!");
```

This line print text on terminal.

`println!` run a rust macro, not a funtion (function are called whitout `!`). It's discussed in chapter 20.

`"Hello, world!"` is a string passed as an aurgument to `println!` inside `()`.

At the end of the line there is a `;`, is used for indicates that this expression is over, than pass to the oders.

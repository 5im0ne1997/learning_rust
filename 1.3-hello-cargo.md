Cargo is the build system and package manager in Rust. It's used for create projects, manage dependencies and more, it's usefull for complex projects but it can be used in every Rust projects.

In order to create a carco project, run the command:

```bash
cargo new hello-cargo
```

It create a new direcotry with `Cargo.toml` config file, `src` directory and inside `main.rs` file. Cargo create also a new `git` repo if the project isn't inside a existing repo. With `--vsc=git` is possible to force repo creation (or create a different repo with other vsc).

The file `Cargo.toml` contain some project informations:

```toml
[package]
name = "hello-cargo"
version = "0.1.0"
edition = "2024"

[dependencies]
```

The firs line `[package]` indicate that the following line configure a package, after this there are the package name, package version and Rust edition.

Inside `[dependencies]` section there is a list of dependencies (aka `creates`) that the project need in order to run, Cargo download all dependencies automatically.

Cargo expects the source code inside `src` directory. The to level directory is used for readme, license, config file and others not related to source code.

With `cargo init` command, we can create `Cargo.toml` automatically, so move the source file inside `src` directory manually.

For compile, run:

```bash
cargo build
```

The default build is in debug mode, so cargo create executale on `./taget/debug` directory. We can run the program inside this directory with the file named as project name.

The first run create also a `Cargo.lock` file, it block dependencies versions and is managed by cargo.

We can use this command to compile and run the code in one command:

```bash
cargo run
```

This command verify if cargo can compile the source code without generate executable:

```bash
cargo check
```

It's usefull because is more faster then `cargo build`, so we can check if the source code is good multiple time and compile at the end.

We can compile for release build, more faster but compile slowly. The executable file is inside `./target/release` directory.

```bash
cargo build --release
```
